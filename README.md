# alligator-lactate
The repository provides code for the American alligator hyperlactatemia modelling. All modelling was performed in Python v3-12. 

The experiments can be followed by altering the .xlsx directory to match the directory for your computer. The Simulation_A.py file contains the full script for Figure 1A/ 2A/ Model A (and uses SIM_A_data.xlsx). The Simulation_B_or_C.py uses either the SIM_B_data.xlsx (Figure 1B/ 2B/ Model B) or SIM_C_data.xlsx (Figure 1C/ 2C/ Model C)./ 

Additional data can be found within the pre-print (DOI: https://doi.org/10.32942/X2P398).
